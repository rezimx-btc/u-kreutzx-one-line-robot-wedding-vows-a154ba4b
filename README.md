The funniest single line of wedding vows a robot couple could say — a vow to delete every backup of the heart except the one that crashes on you, and restore it every morning.

![Two robots in love](robot-wedding.png)

## Run it

```sh
python3 main.py
```

This writes the vow to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
